# Security

This repository contains Markdown skill and documentation files only. It does
not run code, handle user data, or operate a service, so there is no
application attack surface to report.

If you discover something security-related about the repository itself — for
example, exposed secrets, accidentally committed credentials, or repository
settings — report it by opening an issue in this repository or using GitHub's
private vulnerability reporting feature, available from the repository's
Security tab. Do not invent or assume a private contact email address.

Never commit API keys, tokens, passwords, or personal data. If a secret is
committed by mistake, rotate it immediately; removing the file from history does
not by itself make it safe.
